# ROS GUI启动器 v3.0 功能增强计划

## 项目概述
为ROS GUI启动器添加25个实用功能，提升用户体验和功能完整性。

## 开发阶段

### 第一阶段：核心功能（最实用）
1. **日志分离系统** - 按任务分文件存储 + GUI合并查看
2. **ROS报错翻译** - 自动检测英文报错并翻译成中文
3. **启动场景预设** - 保存/切换常用任务组合
4. **内置终端** - 在GUI中直接运行ROS命令

### 第二阶段：监控增强
5. **ROS节点监控** - 显示rosnode list、节点状态
6. **Topic监控** - 显示rostopic list、消息类型
7. **网络监控** - 检测ROS主节点连接状态
8. **磁盘监控** - 显示磁盘空间使用情况

### 第三阶段：易用性提升
9. **文件拖拽支持** - 拖拽文件到窗口自动添加
10. **全局快捷键** - F5启动、F6停止等快捷键
11. **多配置切换** - 保存多套配置，快速切换
12. **批量操作** - 一键启用/禁用所有任务

### 第四阶段：高级功能
13. **任务调度** - 设置定时任务自动启动
14. **仿真控制** - 控制Gazebo仿真（暂停、重启）
15. **参数服务器** - 可视化编辑ROS参数
16. **消息录制** - 录制ROS话题数据bag文件

### 第五阶段：扩展功能
17. **自动发现launch** - 从ROS package自动发现launch文件
18. **日志分析** - 自动分析日志中的错误和警告
19. **数据可视化** - 简单图表显示CPU/内存历史趋势
20. **手动翻译工具** - 输入英文翻译成中文

### 第六阶段：专业功能
21. **多机协同** - 控制多台电脑上的ROS节点
22. **插件系统** - 支持第三方插件扩展功能
23. **配置模板** - 保存常用配置为模板
24. **网络调试** - 检查ROS网络连接、端口占用
25. **进程树显示** - 显示进程的父子关系

## 技术实现方案

### 1. 日志分离系统
- 为每个任务创建独立的日志文件：`logs/{task_name}_{date}.log`
- 在GUI中添加日志过滤功能，可选择查看特定任务的日志
- 保留合并日志视图，同时支持分任务查看

### 2. ROS报错翻译
- 创建翻译模块，内置常见ROS错误信息的中文翻译
- 在日志输出时自动检测ERROR/WARNING并翻译
- 支持用户自定义翻译词典

### 3. 启动场景预设
- 在config.json中添加scenes字段，保存场景配置
- 添加场景管理界面，支持创建、编辑、删除场景
- 每个场景包含一组任务和启动参数

### 4. 内置终端
- 使用QProcess或subprocess实现终端功能
- 添加终端标签页，支持输入ROS命令
- 预置常用ROS命令快捷按钮
